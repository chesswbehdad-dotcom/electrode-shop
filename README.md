# الکترود آریا — سایت فروش و نمایش الکترود جوشکاری (وردپرس)

قالب و افزونهٔ وردپرس برای کاتالوگ آنلاین الکترود جوشکاری با فرم استعلام قیمت. فارسی، راست‌چین و واکنش‌گرا.

## ساختار

| مسیر | توضیح |
|---|---|
| `themes/electrode-shop/` | قالب: اسلایدشو، دسته‌بندی‌ها، محصولات ویژه، تیزر تبلیغاتی، صفحه محصولات با فیلتر، صفحه محصول با جدول مشخصات فنی، تماس با نقشه گوگل، دکمه واتساپ، فونت وزیرمتن |
| `plugins/electrode-catalog/` | افزونه: نوع محتوای «الکترود» + دسته و برند، فیلدهای فنی (AWS، قطر، آمپر، جریان، …)، فرم و مدیریت «استعلام‌ها»، صفحه تنظیمات سایت، محتوای نمونه |
| `mu-plugins/electrode-bootstrap.php` | راه‌اندازی یک‌باره: فعال‌سازی افزونه و قالب، پیوند یکتا، زبان فارسی، منو |

## نصب

1. یک سایت وردپرس تازه بسازید (مثلاً در Local).
2. پوشه‌ها را در `wp-content` کپی کنید:
   - `themes/electrode-shop` ← `wp-content/themes/`
   - `plugins/electrode-catalog` ← `wp-content/plugins/`
   - `mu-plugins/electrode-bootstrap.php` ← `wp-content/mu-plugins/`
3. یک بار صفحه اصلی سایت را باز کنید؛ همه‌چیز خودکار فعال می‌شود. بعد از آن می‌توانید فایل `electrode-bootstrap.php` را حذف کنید.

## تنظیمات

در پیشخوان: **الکترودها ← تنظیمات سایت**
- تلفن، موبایل/واتساپ، ایمیل، آدرس، ساعات کاری، ایمیل دریافت استعلام
- مختصات نقشه گوگل (عرض و طول جغرافیایی)
- متن، دکمه و تصویر هر سه اسلاید
- تیزر: لینک ویدئو MP4، آپارات یا یوتیوب (خالی = تیزر متحرک پیش‌فرض)

## نیازمندی‌ها
وردپرس 6.2+ و PHP 7.4+
